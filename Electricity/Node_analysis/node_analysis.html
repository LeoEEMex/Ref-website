KVL

Fundamentals

Kirchhoff's Voltage Law or KVL, states that the sum of all Voltages drops inside a loop must equal 0.” This law is used to describe how a charge enters and leaves a node on a circuit.
https://www.allaboutcircuits.com/textbook/direct-current/chpt-6/kirchhoffs-voltage-law-kvl/ (information source)

Uses

The main use for this Law is to figure out how much voltage drop at each component inside a loop.

Formulas Rearrangements

The formula can be rearranged to find the current comming into the node or coming out. The rearrangements are as follows:

  • Vsource - V1 - V2 = 0
  • V1 + V2 = Vsource
