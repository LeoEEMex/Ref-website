KCL

Fundamentals

Kirchhoff's Current Law or KCL, states that the sum of all currents entering and exiting a node must equal zero.” This law is used to describe how a charge enters and leaves a node on a circuit.
https://www.allaboutcircuits.com/textbook/direct-current/chpt-6/kirchhoffs-current-law-kcl/ (information source)

Uses

The main use for this Law is to figure out how much current will flow into each branch/component.

Formulas Rearrangements

The formula can be rearranged to find the current comming into the node or coming out. The rearrangements are as follows:

  • Iin = Iout
  • Iin - Iout = 0
  • E.g. : I1 - I2 - I3 = 0

Calculator

This is a calculator that can be used to calculate the current entering or leaving a node. These are the instructions on how to use the calculator:

  • To start the calculator, press "Start"
  • Use numbers only, do not enter any letters or special characters (this inclused SI prefixes).
  • Remember that to find the unknown quantity, you need to let the calculator know at what side is the unknown at, if the unkown is coming into the node, write a 0, if it is coming out of the node, write a 1.
  • Click the "Start" button to begin.
  • Click on the button (Add branch going in) to insert a branch coming into the node.
  • Click on the button (Add branch coming out) to insert a branch coming out of the node.
  • Then click on the "Calculate" button and the result will be calculated and displayed.
  • To reset the calculator, click the "Reset" button.
